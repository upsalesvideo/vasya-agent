## 1. Общие положения

1.1. Настоящая Политика составлена в соответствии с ч. 2 ст. 18.1 Федерального закона от 27.07.2006 № 152-ФЗ
«О персональных данных» и определяет порядок обработки персональных данных и меры по обеспечению их
безопасности, принимаемые Оператором.

1.2. Политика действует в отношении всех персональных данных, которые Оператор получает от посетителей Сайта
(далее — Пользователь, субъект персональных данных).

1.3. Используя Сайт и направляя Оператору свои персональные данные через формы Сайта, Пользователь
подтверждает, что ознакомлен с настоящей Политикой.

## 2. Какие персональные данные обрабатываются

2.1. Данные, которые Пользователь сообщает сам через формы Сайта: {{ПЕРЕЧЕНЬ_ДАННЫХ_ФОРМ: например, имя, номер телефона, адрес электронной почты, текст сообщения}}.

2.2. Данные, которые передаются автоматически при посещении Сайта: IP-адрес, сведения о браузере и устройстве,
дата и время доступа, адреса запрашиваемых страниц, файлы cookie. Подробнее — в Политике использования файлов

2.3. Оператор не обрабатывает специальные категории персональных данных (о расовой принадлежности,
здоровье, политических взглядах и т. п.) и биометрические персональные данные.

2.4. Оператор обрабатывает только те данные, которые необходимы для целей, указанных в разделе 3, и не
собирает избыточные данные.
