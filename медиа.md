# Медиа для сайта: фото, видео, музыка, озвучка через Genosai

Инструмент: `<vasya>/media.py` — прямой REST-клиент Genosai Public API
(https://genosai.io/docs/public-api). Ключ `sdk_live_…` берётся из переменной
`GENOSAI_API_KEY` или файла `<vasya>/genosai_key.txt` (в git не попадает; ключ создаётся в
профиле genosai.io → «API-ключи»). MCP Genosai не используешь: CLI надёжнее и кладёт файлы
сразу в проект.

```bash
cd <vasya>
python media.py balance                                  # кредиты
python media.py models                                   # модели и цены
python media.py estimate video --model veo-3.1-lite      # цена без генерации
python media.py photo <slug> "<промпт>" --name hero --ar 16:9 [--ref фото.jpg]
python media.py edit  <slug> hero "<что изменить>"       # правка по картинке, пропорции сохраняются
python media.py video <slug> "<промпт>" --name promo --duration 6 --ar 16:9 [--image кадр.png] [--no-audio]
python media.py music <slug> "<описание>" --name bg --instrumental
python media.py voice <slug> "<текст>" --name intro --voice Charon
python media.py own   <slug> hero <файл владельца>       # своё фото/видео/трек → в assets под тем же именем
python media.py versions <slug> hero                     # история версий
python media.py restore  <slug> hero 2                   # вернуть версию 2
python media.py list <slug>
```

## Несколько медиа — всегда пакетом, параллельно

Genosai генерирует задачи параллельно. Если нужно больше одного фото или видео, **не
запускаешь их по очереди** — пишешь план в `сайты/<slug>/медиа/план.json` и запускаешь одной
командой:

```bash
python media.py batch <slug> "сайты/<slug>/медиа/план.json"
```

```json
[
  {"kind": "photo", "name": "hero",      "prompt": "…", "ar": "16:9", "ref": ["фото-владельца.jpg"]},
  {"kind": "photo", "name": "service-1", "prompt": "…", "ar": "4:3"},
  {"kind": "video", "name": "promo",     "prompt": "…", "duration": 6, "ar": "16:9", "no_audio": true},
  {"kind": "music", "name": "bg",        "prompt": "…", "instrumental": true},
  {"kind": "voice", "name": "intro",     "text": "…", "voice": "Charon"}
]
```

Скрипт отправляет задачи **с интервалом 1 секунда** (`SUBMIT_INTERVAL`), потом опрашивает
все сразу и по мере готовности скачивает, делает веб-версии и пишет манифест. Пять фото
готовы за ~1 минуту вместо пяти. Правило: один пакет = один медиа-план, утверждённый
владельцем; варианты одного места («сделай 3 варианта hero») — тоже пакетом: три задания
с одним именем `hero` лягут версиями v1–v3, владелец выбирает, `restore` ставит нужную. Упавшие задания
скрипт перечисляет в конце — их перезапускаешь отдельным пакетом, не весь план.

Каждое медиа живёт под **именем места на странице** (`hero`, `about`, `service-1`,
`gallery-3`, `promo`, `bg`, `intro`). Оригиналы всех версий — в `сайты/<slug>/медиа/`,
веб-версии — в `site/assets/`, история и промпты — в `медиа/manifest.json`. Это и есть
память Васи о картинках: по имени он всегда знает промпт, модель и цену.

## Когда генерируем

- На интервью (круг 4) выяснилось, что фото нет или они плохие → предлагаешь сгенерировать.
- Владелец просит видео в шапке, фоновую музыку, озвучку, анимировать фото → планируешь.
- Есть фото владельца → **они главнее** сгенерированных. Генерируешь только недостающее
  и в том же настроении (передаёшь фото владельца как `--ref`, чтобы свет и стиль совпали).
- Лица реальных людей (владелец, команда) — только с их фото через `--ref` на
  `chatgpt-image-2`, никогда «похожий человек» из головы.

## Гейт: медиа-план до траты кредитов

Перед первой генерацией показываешь таблицу и ждёшь «да»:

| Имя | Тип | Где на странице | Модель | Кредиты | Промпт (одной строкой) |
|---|---|---|---|---|---|

Внизу — сумма кредитов и текущий баланс (`media.py balance`). Без «да» не генерируешь.
Исключение: **правка, которую владелец попросил сам** («сделай фон светлее») — просьба и есть
«да»; цену называешь, если она выше 20 кредитов (видео).

После генерации, **до вставки на страницу**, показываешь таблицу `[№ | картинка | промпт]`
(колонки 2–3 равной ширины) и спрашиваешь, что перегенерировать. Видео и музыку присылаешь
файлами через `SendUserFile` плюс s3-ссылка в чат.

## Выбор модели

| Задача | Модель | Цена | Заметки |
|---|---|---|---|
| Фото для сайта, фотореализм, с референсами | `chatgpt-image-2` | 6 | по умолчанию; до 16 референсов |
| Черновики, быстрые варианты композиции | `z-image` | 1 | только текст, без референсов |
| Правка готовой картинки | `nano-banana-2` (8) / `nano-banana` (4) | | `aspect_ratio: auto` сохраняет пропорции |
| Оживить фото владельца (пар, вода, свет, лёгкий наезд) | `grok-imagine-1.5` | 6–16 | image-to-video, 1–15 с, самый дешёвый способ получить видео |
| Фоновое видео в шапке 4–8 с | `veo-3.1-lite` | 30 | без звука `--no-audio`; 720p хватает |
| Сложная сцена, референсы, длинное | `seedance-2.0-fast` / `seedance-2.5` | 160–250 | только по прямой просьбе владельца |
| Фоновая музыка | `suno-v5.5` `--instrumental` | 16 | возвращает 2 варианта, оба показываешь |
| Джингл с текстом | `suno-v5.5` `--style … --title … --lyrics файл` | 16 | кастомный режим |
| Озвучка / приветствие / аудио-отзыв | `gemini-3.1-flash-tts` `--voice Charon` | 1.5 кр/100 симв | порядок голосов: Charon → Kore |

Цены базовые: видео дорожает с длительностью и разрешением — перед планом смотришь
`media.py estimate`. Модели и цены меняются — `media.py models` перед планом.

## Промпты

- Русский язык допустим. Описываешь сцену, свет, объектив, материалы, настроение;
  прямо пишешь «без текста, без логотипов, без водяных знаков».
- Один стиль на весь сайт: одинаковые слова про свет и цвет во всех промптах,
  палитра из `DESIGN.md` («тёплые бежевые и терракотовые тона»).
- Пропорции по месту: hero 16:9 (мобильный hero — отдельный кадр 4:5 или 3:4, не обрезка),
  карточки 4:3, портрет 3:4, квадрат для иконок-иллюстраций.
- Для правки описываешь только изменение и добавляешь «остальное не менять».

## Вставка на страницу

- Фото: `<picture>` / `srcset` с `hero.webp` (до 1600 px) и `hero-800.webp` (мобильные),
  `width`/`height` заданы, `alt` по-русски и по смыслу, `loading="lazy"` везде, кроме hero.
  Лимит: ≤ 200 КБ на картинку.
- Видео в шапке: `<video autoplay muted loop playsinline poster="hero-poster.webp">`,
  ≤ 8 с, ≤ 3 МБ, без звука. При `prefers-reduced-motion` видео не запускается — стоит постер.
  На мобильном — постер вместо видео, если файл больше 1,5 МБ.
- Музыка: **никогда не автоплей**. Видимая кнопка «Включить музыку» с подписью, по умолчанию
  выключено, одна дорожка на сайт, ≤ 4 МБ (при необходимости обрезать `ffmpeg -t 60`).
- Озвучка: кнопка воспроизведения рядом с текстом, который она озвучивает.
- Всё, что сгенерировано, помечаешь в `README.md` проекта: имя → где на странице → промпт →
  как заменить. Владелец без Васи может положить свой файл вместо `hero.webp` + `hero-800.webp`.

## Ручки для владельца: как менять фото

Владелец говорит обычными словами, Вася переводит в команды:

| Владелец говорит | Вася делает |
|---|---|
| «Поменяй фото в шапке на моё» + файл | `media.py own <slug> hero <файл>` → пересобирает веб-версии, вставка уже стоит |
| «Сделай фото в шапке светлее / убери надпись / поменяй фон» | `media.py edit <slug> hero "…, остальное не менять"` |
| «Перегенерируй фото услуги 2, хочу зимний вариант» | `media.py photo <slug> "<старый промпт из манифеста> + изменение" --name service-2` |
| «Не понравилось, верни как было» | `media.py restore <slug> hero <n>` |
| «Покажи, какие варианты были» | `media.py versions <slug> hero` + картинки таблицей |
| «Сделай ещё 3 варианта» | один `batch` с тремя заданиями под именем `hero` (параллельно) → таблица → владелец выбирает → `restore` |
| «Оживи это фото» | `media.py video … --model grok-imagine-1.5 --image <оригинал>` |
| «Убери картинку» | убираешь из разметки, файлы остаются в `медиа/` |

После любой замены: пересобираешь страницу, проверяешь в браузере (1440/375), присылаешь
скриншот блока. Если сайт уже на хостинге — перезаливаешь `deploy.py <slug>` без вопроса.
