# Вася — агент, который делает красивые высококонверсионные сайты

Агент для Claude Code и Codex. Вы пишете «Вася, сделай сайт для …» — он берёт интервью,
согласовывает структуру и стиль, собирает сайт тремя открытыми дизайн-библиотеками, сам
проверяет его на компьютере и телефоне, присылает результат и по команде выкладывает на
ваш хостинг.

**Установка для новичка — [УСТАНОВКА.md](УСТАНОВКА.md)** (10–15 минут, без программирования).

## Что умеет

- **Лендинги, сайты услуг, страницы эксперта, промо-страницы** — статическая папка
  `index.html + styles.css + script.js`, открывается двойным щелчком, ложится на любой хостинг.
- **Интернет-магазины** — каталог, корзина, оформление заказа, админка по паролю, где вы сами
  правите товары, цены, фото, смотрите заказы, импортируете прайс из Excel (Flask + SQLite).
- **Профессиональное интервью** до полной ясности: что продаём, кому, какое одно действие
  должен сделать посетитель, какие есть доказательства, какой стиль (ваши пожелания или
  ссылки на сайты, которые нравятся).
- **Три дизайн-библиотеки без конфликтов**: [ui-ux-pro-max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
  предлагает (стили, палитры, шрифты), [impeccable](https://github.com/pbakaus/impeccable)
  решает (законы дизайна, запреты «ИИ-шаблонов», аудит), [design-motion-principles](https://github.com/kylezantos/design-motion-principles)
  (принципы Эмиля Ковальски) отвечает за движение. Порядок и таблица конфликтов — в `библиотеки.md`.
- **Фото, видео, музыка, озвучка** через [Genosai API](https://genosai.io/docs/public-api):
  генерация, правка картинки по вашему слову («сделай светлее», «верни как было»,
  «поменяй на моё»), версии и откат, несколько медиа параллельно. План с ценой в кредитах
  показывается до траты.
- **Юридический комплект по 152-ФЗ**: политика обработки персональных данных, согласие с
  галочками у форм, политика cookie и баннер (счётчики только после согласия), публичная
  оферта, реквизиты в подвале, шрифты со своего домена. Чего не хватает — Вася напоминает.
- **Самопроверка**: браузер на 1440 / 768 / 375, кнопки, шрифты, ошибки, форма, баннер,
  три аудита библиотек — и только потом результат вам со скриншотами.
- **Выкладка** на ваш хостинг по SFTP одной командой (Beget, Timeweb, reg.ru, любой).

## Как позвать

В чате Claude Code: **«Вася, сделай сайт для …»**, «нужен лендинг под …», «интернет-магазин
с админкой», «поменяй фото в шапке», «выложи сайт на хостинг».

## Что где

| Файл | Что |
|---|---|
| `SKILL.md` | Главная инструкция агента: шаги работы и жёсткие правила |
| `интервью.md` | Круги вопросов и «карточка ясности» — когда хватит спрашивать |
| `библиотеки.md` | Порядок трёх библиотек и таблица разрешения конфликтов |
| `медиа.md` | Фото/видео/музыка/озвучка через Genosai: модели, цены, гейт кредитов, «ручки» замены |
| `право.md` | 152-ФЗ, cookies, оферта: что обязательно, как встроено, что остаётся за владельцем |
| `чек-лист.md` | Проверка перед выдачей: браузер + три аудита + право + медиа |
| `шаблоны/` | `PRODUCT.md`, `DESIGN.md`, `структура.md`; `право/` — политика, согласие, cookie, оферта, сниппеты баннера и формы |
| `media.py` | Genosai: `photo`, `edit`, `video`, `music`, `voice`, `batch`, `own`, `versions`, `restore` |
| `fonts.py` | Скачивает Google Fonts в проект — сайт не обращается к серверам Google |
| `deploy.py` | Выкладка на хостинг по SFTP: `python deploy.py <slug>` → `https://<домен>/<slug>/` |
| `agents/vasya.md` | Определение субагента для Claude Code (`~/.claude/agents/`) — по желанию |
| `сайты/` | Сюда складываются проекты (в репозиторий не попадают) |

## Настройки (не попадают в git)

- `genosai_key.txt` — ключ Genosai `sdk_live_…` (или переменная `GENOSAI_API_KEY`).
- `hosting.json` — доступы к хостингу: `host`, `user`, `password`, `remote_root`, `public_url`.

## Принцип трёх библиотек

**Pro Max предлагает, Impeccable решает, Эмиль двигает.** Одна библиотека — одна зона
ответственности, интервью одно (Васино), источник правды один (`DESIGN.md`).
