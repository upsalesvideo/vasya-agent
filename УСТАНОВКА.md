# Как установить Васю — пошагово, с нуля

Вася — это «агент»: набор инструкций и маленьких программ, которые понимает Claude Code
(или Codex). Вы ставите его один раз, а потом просто пишете в чат: **«Вася, сделай сайт
для …»** — и он ведёт вас за руку: интервью → структура → сайт → проверка → выкладка.

Установка занимает 10–15 минут. Ничего программировать не нужно.

---

## Шаг 0. Что должно быть на компьютере

| Что | Зачем | Как проверить | Где взять |
|---|---|---|---|
| **Claude Code** (или **Codex**) | Сам ИИ-помощник, в котором живёт Вася | Открывается окно/терминал с Claude Code | claude.ai/code → скачать приложение (Windows/Mac) или `npm install -g @anthropic-ai/claude-code` |
| **Node.js** (версия 18+) | Нужен для установки библиотек дизайна | В терминале: `node -v` → видите номер версии | nodejs.org → кнопка LTS |
| **Python 3** (версия 3.10+) | На нём работают скрипты Васи (фото, выкладка, шрифты) | `python --version` | python.org/downloads; **на Windows при установке поставьте галочку «Add Python to PATH»** |
| **ffmpeg** | Только если хотите видео и музыку на сайте | `ffmpeg -version` | Windows: `winget install ffmpeg`; Mac: `brew install ffmpeg` |

> Как открыть терминал: Windows — нажмите Win, наберите `PowerShell`, Enter.
> Mac — Cmd+Space, наберите `Terminal`, Enter. Все команды ниже вставляются туда и
> запускаются клавишей Enter. Проще всего — запускать команды прямо из Claude Code:
> напишите ему «выполни команду …», и он сделает это сам.

## Шаг 1. Установить Васю

Один способ на выбор.

**Способ А — одной командой (рекомендуем).** В терминале:

```bash
npx skills add upsalesvideo/vasya-agent
```

Установщик спросит, куда ставить — выберите Claude Code (или Codex) и «глобально»
(для всех проектов). Готово: Вася лежит в `~/.claude/skills/vasya`.

**Способ Б — вручную, без командной строки.**

1. Откройте https://github.com/upsalesvideo/vasya-agent
2. Зелёная кнопка **Code → Download ZIP**. Распакуйте архив.
3. Переименуйте распакованную папку в `vasya` и положите её:
   - Claude Code: в `C:\Users\<ваше имя>\.claude\skills\` (Windows) или `~/.claude/skills/` (Mac).
   - Codex: в `~/.codex/skills/` (если папки нет — создайте).
   Папки `.claude` / `.codex` скрытые: в проводнике включите «Показывать скрытые файлы»
   или вставьте путь в адресную строку вручную.

Проверка: в чате Claude Code напишите `Вася, ты здесь?` — он представится и спросит,
какой сайт делаем.

## Шаг 2. Установить три библиотеки дизайна

Вася делает красиво не сам по себе, а тремя открытыми библиотеками. Каждая ставится одной
командой в терминале (можно попросить Claude Code выполнить их):

```bash
npx skills add nextlevelbuilder/ui-ux-pro-max-skill
```
```bash
npx impeccable install
```
```bash
npx skills add kylezantos/design-motion-principles
```

Везде выбирайте Claude Code (или Codex) и глобальную установку. После этого в чате
`/impeccable` и `/ui-ux-pro-max` должны подсказываться как команды.

## Шаг 3. Python-пакеты для скриптов Васи

Один раз:

```bash
pip install requests paramiko pillow
```

## Шаг 4. Ключ Genosai — если хотите, чтобы Вася сам делал фото, видео, музыку

Без него Вася ставит на сайт ваши фотографии или честные заглушки; с ним — генерирует.

1. Зарегистрируйтесь на https://genosai.io (работает без VPN и иностранных карт).
2. Профиль → **API-ключи** → «Создать» → скопируйте ключ вида `sdk_live_…` (показывается один раз).
3. Создайте текстовый файл `genosai_key.txt` в папке Васи (`~/.claude/skills/vasya/`) и
   вставьте туда ключ одной строкой. Всё.

Цены за генерацию Вася показывает до того, как потратить кредиты, и ждёт вашего «да».

## Шаг 5. Хостинг — если хотите, чтобы Вася сам выкладывал сайт в интернет

Подходит любой хостинг с SFTP-доступом (Beget, Timeweb, reg.ru и др.). В панели хостинга
найдите данные SSH/SFTP: сервер, логин, пароль. Создайте в папке Васи файл `hosting.json`:

```json
{
  "host": "ваш-сервер.beget.com",
  "user": "логин",
  "password": "пароль",
  "remote_root": "/home/u/логин/ваш-сайт.ru/public_html",
  "public_url": "https://ваш-сайт.ru"
}
```

`remote_root` — папка сайта на хостинге (в панели она обычно называется «корень сайта»
или `public_html`). Сайт откроется по адресу `https://ваш-сайт.ru/<имя-проекта>/`.
Можно не заполнять — тогда Вася отдаст готовую папку, а вы загрузите её через панель
хостинга сами.

## Шаг 6. Первый сайт

Откройте Claude Code в любой папке и напишите:

```
Вася, сделай сайт для моей студии массажа в Казани
```

Дальше он задаёт вопросы (по 2–3 за раз) — отвечайте как есть, своими словами. Когда
ему всё понятно, он покажет структуру и два варианта стиля. Скажете «да» — соберёт сайт,
сам проверит на компьютере и телефоне, пришлёт скриншоты и спросит, выкладывать ли.

Что Вася делает вместе с сайтом, чтобы вы не получили штраф по 152-ФЗ: страницы политики
персональных данных, согласия и cookie, галочки у форм, cookie-баннер, шрифты со своего
домена. Если вы не дали реквизиты (ИНН, ОГРН, адрес, e-mail) — он выложит сайт с
заглушками и напомнит, что их обязательно нужно заполнить.

## Если что-то не работает

| Симптом | Что сделать |
|---|---|
| «Вася» не откликается | Проверьте, что папка называется ровно `vasya` и лежит в `~/.claude/skills/`. Перезапустите Claude Code. |
| `npx: command not found` | Не установлен Node.js — шаг 0. После установки закройте и заново откройте терминал. |
| `python: command not found` (Windows) | Переустановите Python с галочкой «Add Python to PATH». Или используйте `py` вместо `python`. |
| `ModuleNotFoundError: requests` | Шаг 3: `pip install requests paramiko pillow`. |
| Вася пишет «Нет ключа Genosai» | Шаг 4: файл `genosai_key.txt` в папке Васи, внутри одна строка `sdk_live_…`. |
| Вася пишет «Нет доступов к хостингу» | Шаг 5: файл `hosting.json`. Проверьте, что SSH/SFTP включён в панели хостинга. |
| Шрифты на сайте «не те» | Вася скачивает их сам (`fonts.py`); если интернет был недоступен — попросите «скачай шрифты заново». |

Все команды из этой инструкции можно не вводить руками: откройте Claude Code и напишите
«установи всё по файлу УСТАНОВКА.md» — он выполнит шаги сам и спросит только ключи и пароли.
